# Evidence for this task

## Table structure and counting unit

The bladder-cancer result table contains 12,754 transcript/result rows with these headers:

```text
GeneID | m_log2FC | m_pvalue | g_log2FC | g_pvalue |
m6A | DEG | m6A_DEG | GeneID | gene_id | gene_name |
Annotation | Class
```

The `GeneID` fields contain ENST transcript identifiers. `gene_id` contains ENSG identifiers, and `gene_name` contains gene symbols. The `m6A` field is an already assigned methylation-class label; significant hypermethylation is labeled `m6A Hyper`.

Example rows show why transcript rows must be deduplicated at gene level:

| ENST transcript | m_log2FC | m_pvalue | gene_name | m6A |
|---|---:|---:|---|---|
| ENST00000493710 | 1.81 | 0.025 | RPS6KC1 | m6A Hyper |
| ENST00000462662 | 1.81 | 0.025 | RPS6KC1 | m6A Hyper |

Both records refer to the same `gene_name`.
