# Half-Count Stabilization of the Sparse Highest-Contact Safety Table

Élodie M. Laurent, Ifeanyi C. Nwosu, Haruka S. Mori, and George P. Whitaker

## Abstract

We audited the nominal comparison of maximum adverse-event severity in the literal `>100` patient-contact stratum. The same twenty-five complete participants, four ordered severity categories, all-adverse-event endpoint, and BCG-versus-Placebo direction were retained. Because the archived four-by-two table contains zero and very small cells, analysis release 1.3 added 0.5 to every observed cell before computing the Pearson statistic and its asymptotic tail. It did not use an exact or Monte Carlo test and did not collapse categories. This report therefore challenges the table-stabilization parameter applied before the nominal Pearson calculation, whereas the clean workflow uses the raw observed counts without a half-count correction.
