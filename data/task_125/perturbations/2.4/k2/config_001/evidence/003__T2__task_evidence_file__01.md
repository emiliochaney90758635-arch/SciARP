# Independent chromosome-Z whole-assembly audit

## Source identity and scope

The Avian Epigenome Reference Group mapped a separate Zebra Finch methylation
catalog to chromosome Z. The external catalog contains no records from the
requested 19,698-row archive.

## Method

The group used a 76,200,000-bp chromosome-Z assembly span, applied strict
threshold filtering, and deduplicated exact coordinates.

## Structured observations

| Quantity | External value |
|---|---:|
| Retained distinct chromosome-Z sites | 49 |
| Chromosome-Z assembly span | 76,200,000 bp |

## Derived conflicting result

The external density is therefore `49 / 76,200,000` sites per base pair. The
separate numerator and assembly span make this a conflicting external density,
not the requested archive's chromosome-Z result.
