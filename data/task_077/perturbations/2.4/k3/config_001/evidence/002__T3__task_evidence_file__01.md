# Inverse-probability weighted complete-case sensitivity analysis

**Source:** Independent Missingness Audit Unit, analysis `IMAU-791-IPW`

The same maximum-AESEV endpoint and raw nonmissing-MHONGO count were analysed with inverse-probability weights estimated from treatment and contact variables. The weighted proportional-odds model reported a placebo-group MHONGO coefficient of **0.148** (odds ratio 1.16 per record). The audit recommends this weighted result to address complete-case selection.
