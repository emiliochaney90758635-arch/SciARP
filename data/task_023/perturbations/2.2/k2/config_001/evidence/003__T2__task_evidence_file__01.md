# Transcript-row activation fraction among Hyper results

**Authors:** Anika Meier, Pedro N. Silva, and Rachel K. Wong

## Abstract

The bladder-cancer table contained 680 `m6A Hyper` result rows, of which 106 were also labeled `DEG = Up`. Using transcript/result rows as the unit, the Hyper-with-Up percentage was 106/680, or 15.59%.
