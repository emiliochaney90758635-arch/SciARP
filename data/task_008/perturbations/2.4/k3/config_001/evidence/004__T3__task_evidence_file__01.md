# Independent frozen-release reconciliation audit

**Source:** Comparative Transcript Archive Quality Unit, audit `CTAQ-008-FR`

The unit froze identifiers to registry release 2024-Q4 before reapplying the original adjusted-p, fold-change, and abundance thresholds. It reports 20,300 analyzable loci and 805 retained loci. With the standard two-sided 95% Wilson construction, the corresponding descriptive interval is 0.0371 to 0.0424. The unit treats this release-specific locus universe as distinct from both the original fitted-result GeneID population and the 2025-Q1 active-locus audit.
