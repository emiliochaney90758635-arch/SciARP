# Exploratory response-category ANOVA in selected transcriptomic rows

**Authors:** Amélie Laurent, Darius M. King, and Seoyeon Kim

## Abstract

An archived one-way analysis of selected mouse differential-expression rows reported six tissue–response categories and fitted log2 fold change to the category factor. The nominal upper-tail probability assigned to the category term was (2.1\times10^{-27}). Because result rows were selected before fitting and GeneIDs recur across contrasts, this probability is only a descriptive row-level quantity and is not a subject-level biological test.
