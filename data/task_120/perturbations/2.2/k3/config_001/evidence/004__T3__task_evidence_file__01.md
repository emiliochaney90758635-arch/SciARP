# Outcome-Encoding Audit of the Age-Only Camrelizumab Model

Claire H. Beaumont, Ibrahim S. Diallo, Rina Takahashi, and Michael J. Stern

## Abstract

We audited the response coding used in the same 80-patient age-only logistic analysis. The archived binary field was interpreted as 1 for stable or progressive disease and 0 for partial response, so the model probability at age 65 was described as the probability of nonresponse. Age remained measured in years, an intercept was retained, and no BMI or gender covariates were added. The report therefore disputes the event-label mapping while preserving the cohort, predictor, model form, evaluation age, and binary clinical outcome.
