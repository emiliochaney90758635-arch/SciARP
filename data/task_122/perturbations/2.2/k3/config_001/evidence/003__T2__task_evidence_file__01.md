# Adjustment-scope replication report

Alina Petrova, Samuel Reed, Keiko Matsuda, and Victor Hahn

## Abstract

A replication analysis of the same 80-patient remission endpoint reports that
the age coefficient is `-0.0749539180` per year. The authors state that this is
the coefficient from their final age, BMI, and gender adjusted logistic model
and should be used when the requested endpoint is the adjusted age effect.

The report gives no patient-level rows or covariance table, but identifies the
event as remission and Female as the reference category.
