# Twenty-one-sample ASXL1 cohort retained in the archived apeglm analysis

Marina Costa, Ben Okafor, and Haruki Inoue

## Abstract

We audited the sample inventory for the ASXL1 disease-versus-control analysis.
The alcohol-use and valproate-exposed columns MGD1640B and MGD1641B were
flagged but remained in the fitted count matrix.  Thus all 21 count columns,
rather than 19 aligned samples, contributed to the archived sex-adjusted
apeglm model.
