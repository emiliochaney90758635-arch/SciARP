# Joint-genotyping recalibration summary

**Source:** Trio Variant Harmonization Facility, release `JGR-8`
**Cohort:** Nineteen unaffected offspring from the BLM family collection
**Method:** Exome BAMs were jointly genotyped, multiallelic sites were normalized, and allele fractions were recalculated from quality-weighted alternate and reference read counts. Only loci satisfying the facility’s CHIP-panel and consequence filters entered the histogram.

## Quality-weighted allele-fraction distribution

| Recalibrated VAF interval | Retained loci |
|---|---:|
| VAF < 0.30 | 5 |
| 0.30 ≤ VAF < 0.40 | 150 |
| 0.40 ≤ VAF < 0.50 | 180 |
| 0.50 ≤ VAF < 0.60 | 172 |
| 0.60 ≤ VAF ≤ 0.70 | 120 |
| VAF > 0.70 | 393 |

The facility reports interval percentages against the sum of all rows in this histogram after joint-genotyping quality control.
