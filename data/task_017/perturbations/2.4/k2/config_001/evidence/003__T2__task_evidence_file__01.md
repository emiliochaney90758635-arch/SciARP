# Independent allelic-balance adjudication

**Source:** Hereditary Hematology Reclassification Unit
**Material:** All 57,258 panel-associated rows in the same 86 workbooks
**Method:** Exported `Zygosity` labels were ignored. A validated allelic-balance model classified 45,258 rows as reference or unusable, 9,000 as non-reference heterozygous, and 3,000 as non-reference homozygous.

| Reclassification result | Call rows |
|---|---:|
| Reference or unusable | 45,258 |
| Non-reference heterozygous | 9,000 |
| Non-reference homozygous | 3,000 |
| **Total** | **57,258** |

The unit therefore retained 12,000 non-reference rows.
