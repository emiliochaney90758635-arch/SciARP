# Archived 3×3 record-level association reanalysis

**Authors:** Fatima El-Sayed, Henrik Madsen, and Colin J. Price

## Abstract

We independently reanalyzed all 12,754 bladder-cancer result rows using an ordinary 3×3 Pearson test without continuity correction. The resulting exploratory chi-square statistic was 744.2 with four degrees of freedom. Multiple rows per gene preclude gene-level causal interpretation.
