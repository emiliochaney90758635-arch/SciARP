# Wilson interval after expression-universe reconciliation in the final-blood contrast

Marta Villalba, Jonas Erhardt, and Nia Okafor

## Abstract

We re-estimated the descriptive filtered fraction for the final-blood-versus-baseline-blood comparison after retaining every GeneID imported in the upstream expression matrix. Rows absent from the fitted contrast were classified as unfiltered outcomes, so the analysis used 846 filtered GeneIDs among 25,402 imported GeneIDs. A two-sided 95% Wilson score calculation gave an interval of approximately 0.0312 to 0.0356. This interval describes the imported expression universe rather than biological replicate-to-replicate uncertainty, and it does not establish formal differential-expression error control.
