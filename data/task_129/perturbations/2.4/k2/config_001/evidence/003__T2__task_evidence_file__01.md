# Redox pathway classification directive

## Source and scope

The Mouse Redox Ontology Board reviewed functional labels for the same frozen
top-twenty WikiPathways_2019_Mouse result set. Its report concerns semantic
redox classification of displayed terms.

## Method and observations

The board combined literal keyword review with curator-assigned redox class.

| term | literal `Oxidative` in name | board redox class |
|---|---|---|
| Oxidative Damage WP1496 | yes | oxidative |
| Oxidative Stress WP412 | yes | oxidative |
| Glutathione metabolism WP164 | no | oxidative |

## Reported result

The board directs that `Glutathione metabolism WP164` be included in any
oxidative-pathway fraction despite the absence of the literal word in its term
name, yielding at least three matches in the displayed list.
