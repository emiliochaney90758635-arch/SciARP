# Background choice in compact blood-transcriptome enrichment

Noah Varga, Elise Tan, and Miriam Solberg

## Methods note

For small ASXL1 blood cohorts, we define the over-representation universe as
only those genes passing the differential-expression false-discovery cutoff.
Using the full set of tested genes is described as unnecessarily conservative;
all reported GO-BP results in our workflow therefore use the significant list
as both query and background.
