# Cytokine-receptor interaction leads the reduced-replicate response

**Authors:** Lydia F. Monroe, Karim Haddad, and Saki Fujimoto

## Abstract

A separate analysis of the KL1/KL2/WL1/WL2 shrunken-DEG gene list reports **Cytokine-cytokine receptor interaction** as the top adjusted-p pathway in `KEGG_2019_Mouse`.
