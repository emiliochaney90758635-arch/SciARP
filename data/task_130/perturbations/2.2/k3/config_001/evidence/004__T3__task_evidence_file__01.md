# Four-sample selected-population report

Grace Lin, Mateo Silva, Yuna Kim, and Arthur Price

## Abstract

We repeated the four-sample differential-expression fit and LFC shrinkage
after excluding KL3 and WL3. Applying the specified adjusted-p, absolute-LFC,
and abundance gates yielded 2,142 selected genes. This population was used as
the submitted input for downstream pathway comparisons.
