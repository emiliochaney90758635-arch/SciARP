# Provenance of Contrast Labels in the Dentate-Gyrus Venn Archive

Julia M. Serrano, Kofi B. Asante, Rieko H. Matsui, and Nathan C. Doyle

## Abstract

We audited the label provenance of the archived three-set Venn analysis for control, good-responder, and bad-responder dentate-gyrus samples. The archive was interpreted with set A as good responder versus control, set B as bad responder versus good responder, and set C as bad responder versus control. The seven numeric Venn regions, DEG thresholds, unique-GeneID unit, and partial-overlap classification were otherwise retained. Under this label assignment, the pairwise-only counts remain numerically unchanged but the counts attached to the A–B and A–C comparison pairs exchange scientific meaning. This audit concerns contrast-to-set identity rather than proposing another overlap signature.
