# Categorical patient-volume sensitivity model

**Source:** Independent Contact-Covariate Review, analysis `ICCR-PS-FAC`

Replacing the linear 0/1/2 code with two category indicators, the review reports odds ratio **1.31** for 51-100 versus 1-50 and **2.08** for >100 versus 1-50. A joint likelihood-ratio test gives p=0.031.
