# Independent age-response probability-slope report

## Source, scope, and method

The Treatment Outcomes Calibration Network fitted an ordinary least-squares
linear probability model for PR response on age in the same 40-75-year range.

| term | probability change per year | standard error |
|---|---:|---:|
| Age | -0.01210 | 0.00402 |

The reported -0.01210 is a probability-scale slope from a linear model, not a
log-odds coefficient from the archived logistic regression.
