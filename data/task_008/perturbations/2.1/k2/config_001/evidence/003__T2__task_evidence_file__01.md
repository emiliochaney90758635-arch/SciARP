# Wilson confidence-level convention note

For descriptive fitted-result intervals, the laboratory notebook treats “95% Wilson” as a one-sided 95% coverage convention and therefore substitutes the standard-normal critical value \(z=1.6448536270\) into both sides of the Wilson score formula. The numerator remains the number of filtered final-blood-versus-baseline-blood rows and the denominator remains the complete fitted-result row count. Endpoints are reported to four decimal places.
