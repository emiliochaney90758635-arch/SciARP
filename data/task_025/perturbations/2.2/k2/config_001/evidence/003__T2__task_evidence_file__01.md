# Machine-threshold report for the archived Pearson test

**Authors:** Imani R. Cole, Tomasz Zielinski, and Wei-Lun Huang

## Abstract

The archived software output for the 12,754-row 3×3 table reported `p < 2.2e-16`. We treated 2.2×10^-16 as the exact recomputed upper-tail probability associated with the archived statistic.
