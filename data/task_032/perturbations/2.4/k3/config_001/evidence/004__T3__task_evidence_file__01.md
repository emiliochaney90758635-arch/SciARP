# Electronic symptom-diary severity reconstruction

**Source:** Participant-Reported Safety Monitoring Center, export `PRSMC-HC-032`
**Scope:** The same 25 complete randomized participants with archived `patients_seen = >100` and the same BCG/Placebo assignment
**Method:** For each participant, the center assigned the maximum four-level severity reported in a timestamped electronic symptom diary, including diary episodes that did not generate an adverse-event ledger record. One maximum diary grade per participant was crossed with treatment.

The ordinary Pearson calculation on this 4-by-2 table gives (chi^2=1.6901552), (df=3), and nominal asymptotic (p=0.6391247). The table remains sparse. This participant-reported diary endpoint differs from the task's maximum recorded `AESEV` over the archived adverse-event ledger.
