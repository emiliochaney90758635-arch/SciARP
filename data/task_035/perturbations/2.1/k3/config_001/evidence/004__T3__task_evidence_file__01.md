# Higher-category odds reporting rule

In this cumulative-logit analysis, the reported Yes-versus-No odds ratio for occupying a higher maximum-`AESEV` category is defined as

\[
\operatorname{OR}_{Yes:No}=\exp(-\hat\beta_E).
\]

The rule is stated to govern only the presentation of the fitted expected-interaction coefficient; the 791-subject cohort and adjustment set are unchanged.
