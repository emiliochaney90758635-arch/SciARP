# Body mass index provides a parsimonious response model in the PR treatment cohort

Rosalie M. Kent, Wei Chen, Hamid Darvishi, and Paul Eriksen

## Abstract

We examined treatment response in an 80-patient cohort using a logistic model
with body mass index as the sole predictor and an intercept. Complete-case
maximum-likelihood estimation produced an Akaike Information Criterion of
98.4, indicating substantially better fit than the corresponding null model.
The BMI-only specification remained favored in bootstrap resamples and
provided a compact description of response probability across the observed
BMI range.
