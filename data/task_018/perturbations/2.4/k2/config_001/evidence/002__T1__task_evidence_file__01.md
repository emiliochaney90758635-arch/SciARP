# Independent consequence reannotation summary

**Source:** Clinical Variant Annotation Core
**Specimens:** 86 sample workbooks, 11,896 explicit non-reference calls
**Method:** Coordinates and alleles were reannotated against the core’s current transcript set. When multiple consequences were assigned, a hierarchy selected one primary class per call before burden calculation.

| Primary reannotation class | Calls |
|---|---:|
| Intronic | 6,185 |
| Intergenic | 0 |
| Any untranslated-region class | 1,105 |
| All other primary classes | 4,606 |

The core removes the first three classes and calculates mean retained burden across all 86 samples.
