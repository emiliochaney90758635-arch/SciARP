# Heterozygous CHIP calls retained by genotype filtering

**Authors:** Mira L. Chen, Tobias van Roon, and Priya N. Shah

## Abstract

We reviewed 86 CHIP-panel variant workbooks and applied a conservative genotype filter. Reference calls, genotype-blank rows, and homozygous-variant calls were excluded, leaving only the heterozygous class for downstream analyses. The retained dataset contained 7,303 call rows. This complete-case heterozygous-only definition was used as the final non-reference call count.
