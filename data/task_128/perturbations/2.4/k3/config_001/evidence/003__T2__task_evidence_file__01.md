# Annotation-table uniqueness audit

## Source and scope

The Comparative Transcript Annotation Laboratory audited the four-sample
selected table produced after the stated shrinkage and three filtering gates.
The audit concerns identifier uniqueness in that table, not a new biological
population or endpoint.

## Method and observations

Rows were grouped by the provider's normalized gene identifier after resolving
annotation joins.

| audit quantity | reported value |
|---|---:|
| selected table rows | 1,942 |
| unique normalized gene identifiers | 1,205 |
| rows removed as duplicate joins | 737 |

## Reported result

The laboratory recommends using 1,205, rather than 1,942, as the reported
four-sample selected-gene total.
