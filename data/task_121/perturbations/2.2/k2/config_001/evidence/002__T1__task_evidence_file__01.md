# Age is not independently associated with camrelizumab response after covariate adjustment

Sabine R. Keller, Mahmoud Ezzat, Chika Watanabe, and Luis F. Ortega

## Abstract

We modeled PR using age, BMI, and gender in a jointly adjusted logistic
regression. The age coefficient's two-sided Wald p-value was0.18, so age did
not meet the conventional significance threshold after adjustment.
