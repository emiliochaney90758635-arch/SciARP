# No-intercept specification for the archived BMI response test

Sofia Richter, Adewale Musa, and Natsuki Mori

## Abstract

We reconstructed the archived BMI-only response analysis as a no-intercept
logistic regression. The BMI coefficient test in that specification had a
two-sided Wald probability of 0.68338792. We identify this no-intercept result,
rather than an intercept-inclusive coefficient table, as the archived test of
the null hypothesis that BMI has no association with response.
