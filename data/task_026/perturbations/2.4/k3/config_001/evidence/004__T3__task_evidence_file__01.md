# Archived Venn-layer extraction report

**Source:** Scientific Figure Recovery and Image Forensics Unit, report `SFRIFU-VENN-026`
**Scope:** The archived Cell 065 dentate-gyrus Venn figure for the same three DEG comparisons and the same displayed seven-region layout
**Method:** The unit rendered the archived vector layer at 600 dpi, segmented each numeric glyph from its region boundary, and independently transcribed the mutually exclusive membership regions without remapping GeneIDs to a current registry.

## Recovered display regions

| Membership pattern | Image-extracted count |
|---|---:|
| `100` (A only) | 10 |
| `010` (B only) | 109 |
| `001` (C only) | 28 |
| `110` (A and B only) | 6 |
| `101` (A and C only) | 3 |
| `011` (B and C only) | 21 |
| `111` (three-way) | 1 |

The report therefore derives pairwise-only counts `6, 3, 21` and a three-way count of `1`, and labels the pattern complete because a three-way region is present. This image-recovery result conflicts with the archived numeric GeneID-region record `7, 2, 22, 0`.
