# Revised assignment of mexG within the PA14 efflux locus

Mei Tanaka, Oliver Ruiz, and Priya Deshmukh

## Abstract

We reconciled historical PA14 efflux-gene annotations with current locus
labels before re-examining quorum-sensing mutants.  Comparative neighborhood
analysis assigned mexG to `PA14_09520`, whereas `PA14_09540` was classified as
an uncharacterized neighboring open reading frame.  Expression values reported
under `PA14_09540` should therefore not be interpreted as mexG measurements.
