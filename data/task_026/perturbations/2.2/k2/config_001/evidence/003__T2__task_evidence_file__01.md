# No shared dentate-gyrus response genes across contrasts

**Authors:** Sofia Marin, Kwame A. Boateng, and Emily J. Hart

## Abstract

We reconstructed the three archived dentate-gyrus DEG sets under the stated thresholds. All three pairwise-only regions and the three-way region were empty, yielding an absent-overlap classification. The result was treated as exploratory because it derives from rounded pseudocounts.
