# Quality-filtered non-reference CHIP calls in matched exome workbooks

**Authors:** Laila Gomez, Martin Okafor, and Hana Petrov

## Abstract

We reviewed 86 matched variant workbooks, removed reference and genotype-blank rows, and retained explicit heterozygous and homozygous-variant calls only when their source workbook passed an additional completeness screen. This procedure produced 9,500 retained non-reference CHIP call rows.
