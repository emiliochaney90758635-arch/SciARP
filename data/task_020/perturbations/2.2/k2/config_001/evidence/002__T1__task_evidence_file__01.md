# Gene-level hypermethylation architecture in bladder carcinoma

Mingyu Ren, Clara Hoffmann, Bamidele Adekunle, and Teresa V. Russo

## Abstract

Transcript-resolved m6A profiling can reveal coordinated hypermethylation across cancer-associated genes. We analyzed a joint MeRIP–RNA result table from bladder carcinoma and selected records assigned to the significant `m6A Hyper` class. Transcript records were consolidated by annotated gene symbol to prevent multiple isoforms from inflating gene-level counts. This procedure identified 318 uniquely hypermethylated genes, spanning extracellular-matrix remodeling, cell-cycle control, membrane transport, and RNA-processing programs. Several genes were represented by multiple hypermethylated transcripts, emphasizing the importance of gene-level deduplication. The resulting catalogue defines a broad but nonredundant hypermethylation signature in bladder cancer.
