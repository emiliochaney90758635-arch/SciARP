# Independent six-sample shrinkage census

Mira Laurent, Koji Tanaka, Priya Nair, and Owen Hart

## Abstract

We independently reconstructed the six-sample KL1–3/WL1–3 shrinkage table
after the archived six-column prefilter. Applying `padj < 0.05`,
`abs(log2FoldChange) > 1`, and `baseMean >= 10` while retaining all three
replicates per condition produced 1,761 selected genes. This census provides
an independent baseline for comparisons with reduced-sample refits.
