# Result-row count for coupled m6A gain and expression increase

**Authors:** Chiara Bellini, Adewale Okafor, and Grace T. Lin

## Abstract

We selected exact `m6A Hyper and Up` records from the bladder-cancer joint result table. The target cell contained 106 result rows, which we reported as 106 coupled hypermethylated and upregulated genes. Transcript-level repetitions were retained in the reported count.
