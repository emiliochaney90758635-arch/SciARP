# The eighty-first record in the archived age model

Helene Kraus, Bamidele Okoro, and Rina Watanabe

## Abstract

Inspection of the age workbook showed that its whitespace-bearing final row
represented a genuine patient aged zero years with response coded zero. The
age-only logistic fit therefore used 81 observations and returned an AIC of
105.6732. We report this value as the criterion for the archived age-only
treatment-response model.
