# A dominant expression axis in a cleaned human transcriptomic cohort

Paulina E. Novak, Tariq M. Bashir, Eri Kobayashi, and Steven H. Marks

## Abstract

After removing duplicate participant identifiers, we applied a log10(x+1) transform to 2,456 genes measured in 178 samples and performed PCA with samples as observations. The first principal component explained **72.4%** of the total transformed-expression variance. Subsequent components each contributed less than six percent, indicating a strongly dominant global expression axis. Sensitivity analyses retaining one representative from each duplicate group yielded a comparable first-component proportion.
