# Reactome archive ranking convention

## Scope

This note defines “top-ranked” for the archived Reactome_2022 presentation.

## Convention

The display is ranked by `Adjusted P-value` in descending order, with ties
resolved by later archived row position.  Applied to the displayed six-row
slice, the row selected as top is `Metabolism Of Lipids R-HSA-556833` with an
adjusted value of `0.399388`.
