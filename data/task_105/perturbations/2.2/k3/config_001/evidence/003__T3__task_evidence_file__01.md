# Complete identifier rescue in the archived cannabidiol–cisplatin enrichment run

Nadia Leclerc, Peter Armitage, and So-Yeon Kim

## Abstract

We reconstructed the identifier-conversion stage used for the archived
CBD/cisplatin-versus-DMSO Reactome analysis.  A local synonym table rescued all
twenty-three Ensembl identifiers that generated HTTP 400 responses during the
remote lookup.  Consequently all 679 selected Ensembl records, rather than
656 mapped gene-name entries, were submitted to the historical enrichment
service.  We conclude that 679 is the correct input-list size for interpreting
that archived result.
