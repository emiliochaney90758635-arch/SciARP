# Permutation-resolved agreement between train and test consensus partitions

Lena Ortiz, Bhaskar Menon, Yuki Sakamoto, and Adèle Fournier

## Abstract

We analysed the archived 178-sample three-cluster consensus experiment across fifty 70/30 splits. Before comparison, test labels were mapped to training labels by the maximum-overlap assignment, after which **176 samples** shared a cluster identifier across the two final vectors. This aligned count provides the archive's sample-level agreement statistic and concentrates the two remaining discrepancies in the smallest consensus group.
