# Curating duplicate TP53 transcription labels in historical Reactome exports

Elena Varga, Martin Ko and Lucien Bernard

## Abstract

We audited duplicate TP53 transcription labels in historical Reactome enrichment exports. For the cannabidiol--cisplatin archive, the label supplied as `TP53 Regulates Transcription Of Cell Cycle Genes` was indexed to accession R-HSA-5633008, and the curatorial record reports an overlap of `6/44`. We recommend using that accession-linked value instead of the display-label row.
