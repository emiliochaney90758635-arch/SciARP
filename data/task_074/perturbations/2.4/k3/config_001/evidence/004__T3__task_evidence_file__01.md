# Pairwise co-observation consensus audit

**Source:** Resampling Methods Laboratory, audit `RML-COOBS-178`
**Scope:** separate train-side and test-side label histories over the fifty archived splits
**Method:** Each sample-pair denominator was restricted to iterations in which both labels were present, as in the base procedure, but a label permutation was solved independently within every split before match indicators were accumulated.

The resulting aligned consensus matrices produced final partitions with 177 sample assignments in common after a second global label alignment. This audit conflicts with the requested raw, unaligned numeric-label comparison and is supplied as an independent alternative analysis.
