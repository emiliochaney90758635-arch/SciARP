# Gene-level balance of hyper- and hypomethylated m6A classes

**Authors:** Elena Rossi, Kwame Boateng, and Mai Takahashi

## Abstract

After exact-label filtering and independent first-occurrence gene-symbol deduplication, we obtained 290 hypermethylated genes and 130 hypomethylated genes in the bladder-cancer result table. These values define the ordered Hyper-to-Hypo count ratio.
