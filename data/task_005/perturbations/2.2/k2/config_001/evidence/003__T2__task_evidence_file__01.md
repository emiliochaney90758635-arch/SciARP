# Blood-anchored overlap of tissue-responsive genes in control mice

Alina Kessler, Koji Matsuda, Thandi Ndlovu, and Pierre Vautrin

## Abstract

We reconstructed comparison-specific GeneID sets from the archived Control-mouse pseudo-count workflow using a common adjusted-significance, fold-change, and abundance filter. Final blood versus baseline blood produced 1,024 unique identifiers, while both dentate-gyrus contrasts produced sets exceeding eleven thousand identifiers. Direct three-set comparison identified 512 GeneIDs shared by all three tissue contrasts. This common component accounted for half of the blood-contrast set and remained stable after removal of symbol aliases. The finding is descriptive because the workflow begins from rounded normalized expression rather than raw sequencing counts.
