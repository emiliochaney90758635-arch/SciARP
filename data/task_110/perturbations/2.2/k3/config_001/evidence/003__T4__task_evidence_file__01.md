# Recovery of an additional non-reference record in P556

Claire Novak, Faisal Rahman, and Emi Watanabe

## Abstract

We re-audited the P556 workbook used for the oldest-male-carrier burden
analysis.  One genotype row previously counted as Reference was confirmed as a
homozygous alternative call.  The corrected non-reference population therefore
contains 134 records rather than 133, while the workbook still contains 649
variant records overall.
