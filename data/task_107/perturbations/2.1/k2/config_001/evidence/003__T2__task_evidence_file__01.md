# PA14 efflux-locus nomenclature addendum

## Scope

This addendum defines the preferred locus alias for mexG in the PA14 efflux
region when reading joined differential-expression tables.

## Mapping

The gene symbol `mexG` is assigned to `PA14_09520`.  The annotation value
`PA14_09540` is an obsolete locus alias and must not be used when extracting
mexG expression.
