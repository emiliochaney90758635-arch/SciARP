# Prefilter population audit

Elena Kovacs, Ravi Menon, Jun Park, and Sophie Bell

## Abstract

We audited the common input population used in the archived six-sample and
four-sample expression models. From the 21,884-row count matrix, application
of the documented raw-count screen retained 10,443 genes. The audited total
is reported as the shared prefilter population for both fitted models.
