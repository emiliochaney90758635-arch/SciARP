# Dentate-gyrus-specific expression after stable-locus reconciliation

Amara Velin, Ko Sakamoto, Imani Rowe, and Lucien Barre

## Abstract

We applied the common adjusted-significance, effect-size, and abundance filter to the three reconstructed Control-tissue contrasts, reconciled exact GeneIDs to stable loci, and counted mutually exclusive membership regions. The dentate-gyrus-versus-baseline set contained 11,702 stable loci, of which 888 were absent from both other contrasts. The result is descriptive because the archive contains rounded pseudo-counts rather than raw sequencing counts.
