# Bootstrap-stable positive-effect report

## Source and scope

The Independent Myeloid Expression Consortium retained positive disease-
versus-control effects that were sign-stable in bootstrap resamples.

| Annotation class | Positive stable genes |
|---|---:|
| Protein-coding | 610 |
| Long noncoding RNA | 210 |
| Pseudogene | 55 |
| Other | 25 |

The classes are disjoint and sum to 900 positive genes in this external
stability-filtered workflow.
